# User-supplied reference: black, graphite and lime

The user rejected the earlier cartoon/cream and emerald/gold interpretations and supplied an actual Blackjack Wiz promotional screenshot. This reference supersedes the unverified stylistic assumptions in the earlier studies.

Observed visual direction: nearly black canvas; graphite panels and understated vertical gradients; small lime-yellow accents; simple gray outline icons; crisp white playing cards with plain black/red suits; restrained typography and rounded, substantial action buttons. No illustrated avatars, ornate card artwork, gold casino decoration or green felt.
