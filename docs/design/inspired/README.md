# Offsuit Games / Blackjack Wiz inspired visual study

Four generated concept boards, two per direction, responding to the user's request to see styles before any implementation. These are original visual interpretations, not current screenshots or verified replicas of either product. Requests to reference sites and the App Store search endpoint were blocked by this environment's destination policy, so no claims about their exact present-day interfaces are made.

## Scope

All images are visual proposals. Cards, pot amounts, chart fills and reference-action placeholders are illustrative, not strategy advice or new solver results. Generated schematic charts may differ from the exact 169-cell matrix required by the real app; final implementation must use the existing data and components. Button emphasis is visual exploration, not a cue about the best poker action. A polished implementation would preserve equal decision emphasis and accessible answer feedback.

The working app, training logic, chart data and existing tests are unchanged. New imagery was generated with the image-generation tool; the original generated files are also retained in `/workspace/generated_images`. No original brand assets or logos were copied into the app.
