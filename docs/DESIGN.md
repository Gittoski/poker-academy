# Guided learning and visual system

The default experience is a small next step, not a library of every poker concept at once. Basics, Deeper strategy and Mastery practice are cumulative stages. Each lesson uses Learn → Example → Check → Apply, followed by a contextual bridge to the next lesson. Two different checks must pass; a wrong answer receives reasoning and a retry. Completed lessons remain reviewable. Old completions are honored, and incomplete imported paths cannot skip prerequisites. Free practice and the table are optional sandboxes, separate from lesson unlocks. A course completion or XP level is not evidence of expert poker ability.

The visual system uses midnight navy (#090F16), elevated slate (#131E2B), emerald/mint (#83E2BC), and warm ivory (#F1F1E9). Rounded surfaces, restrained borders, compact labels and a consistent spacing rhythm establish hierarchy. The next lesson has a distinct emerald surface. Progress is visible without dominating the lesson. Navigation stays at the bottom while content scrolls; card suits have full accessible names, and hidden cards never expose their value to assistive technology.

Screen and lesson transitions last 220 ms; dealt cards stagger by 30 ms. Press feedback uses a restrained 0.98-scale spring. There are no perpetual or distracting animations. The OS reduced-motion preference defaults to respected until known, disables entrances and press motion, and reacts to preference changes while the app runs. Feedback uses words as well as color. These behaviors are tested in Chromium; native animation smoothness, VoiceOver and Dynamic Type remain part of the iPhone release gate.

Shared components and palette live in `src/components/Visuals.tsx` and `ui.ts`. The seven browser suites cover all twelve guided lessons, restored progress, functional trainers/table, offline reload, responsive layouts, WCAG A/AA scans of resting screens and a worked example, visible cards, persistent navigation, and live reduced-motion behavior. Accessibility scans wait for the bounded entrance transition to finish; this is not a claim of full manual accessibility certification.
